# Planejamento das Sprints

O desenvolvimento do Projeto Integrado Inovação – Sistema de Gerenciamento de Estoque será organizado utilizando a metodologia Scrum, com divisão das atividades em três sprints.

O quadro Scrum será utilizado para acompanhar o andamento das tarefas, organizando-as entre as etapas Backlog, Sprint Atual, Em Progresso e Concluído.

## Sprint 01 — Análise e Planejamento

**Objetivo:** estruturar o projeto, analisar o problema apresentado no enunciado e definir os primeiros artefatos necessários.

**Duração:** 1 semana.

**Principais tarefas:**
- Análise da situação-problema.
- Definição dos objetivos do sistema.
- Organização do quadro Scrum no Trello.
- Planejamento das sprints.
- Criação da tabela verdade.

**Resultado esperado:** situação-problema documentada, quadro Scrum organizado e tabela verdade desenvolvida.

## Sprint 02 — Estruturas de Dados e Algoritmos

**Objetivo:** definir a organização dos dados e os algoritmos necessários para o funcionamento do gerenciamento de estoque.

**Duração:** 1 semana.

**Principais tarefas:**
- Definição das estruturas de dados.
- Desenvolvimento do algoritmo de cadastro.
- Desenvolvimento do algoritmo de consulta.
- Desenvolvimento do algoritmo de movimentação.
- Desenvolvimento dos algoritmos de relatórios.

**Resultado esperado:** estruturas de dados e algoritmos documentados e alinhados aos requisitos do projeto.

## Sprint 03 — Casos de Uso e Finalização

**Objetivo:** concluir os artefatos do projeto e organizar a documentação final.

**Duração:** 1 semana.

**Principais tarefas:**
- Criação do Diagrama de Casos de Uso.
- Descrição dos casos de uso.
- Organização das evidências.
- Montagem do relatório final.
- Revisão dos requisitos do projeto.

**Resultado esperado:** todos os requisitos acadêmicos atendidos, documentação organizada e relatório final preparado para entrega.

## Fluxo de Trabalho

As tarefas serão movimentadas no quadro Scrum conforme seu estado de execução:

**Backlog → Sprint Atual → Em Progresso → Concluído**

O quadro também será utilizado para registrar a evolução das sprints e gerar as evidências solicitadas no projeto.
