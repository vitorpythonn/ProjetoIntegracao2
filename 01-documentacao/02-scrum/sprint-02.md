# Sprint 02 — Estruturas de Dados e Algoritmos

## Objetivo

Definir a organização dos dados e os algoritmos necessários para o funcionamento do Sistema de Gerenciamento de Estoque.

## Duração

1 semana.

## Tarefas realizadas

- Definição das estruturas de dados.
- Desenvolvimento do algoritmo de cadastro.
- Desenvolvimento do algoritmo de consulta.
- Desenvolvimento do algoritmo de movimentação.
- Desenvolvimento dos algoritmos de relatórios.
- Definição do procedimento para consulta do histórico de movimentações.

## Progresso

100% das tarefas planejadas foram concluídas.

## Resultado

Foram definidas as estruturas de dados para produtos, categorias, movimentações, localizações, compras e notas fiscais.

Também foram documentados os algoritmos de cadastro, consulta, movimentação e geração de relatórios, incluindo a consulta do histórico de movimentações.

Os algoritmos foram definidos de acordo com os requisitos do projeto, mantendo a solução simples e sem adicionar funcionalidades desnecessárias.

## Desafios encontrados

Durante a elaboração dos arquivos, foi necessário revisar a formatação e a organização de alguns documentos para garantir que o conteúdo estivesse corretamente registrado e pudesse ser validado.

## Melhorias para a próxima Sprint

Na próxima sprint será realizada a criação do Diagrama de Casos de Uso, a descrição dos casos de uso e a organização das evidências e da documentação final.

## Situação da Sprint

Sprint 02 concluída.
