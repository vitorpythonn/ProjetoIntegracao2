# Projeto Integrado Inovação — Sistema de Gerenciamento de Estoque

## 1. Introdução

Este projeto apresenta o desenvolvimento de uma proposta de Sistema de Gerenciamento de Estoque para uma empresa de comércio eletrônico.

A solução foi planejada para auxiliar no controle dos produtos armazenados, suas quantidades, localizações e movimentações.

## 2. Situação-Problema

A empresa enfrenta dificuldades relacionadas à falta de produtos, excesso de estoque, localização dos itens nos depósitos e acompanhamento das movimentações.

Diante desse cenário, foi definida uma solução capaz de organizar as informações do estoque e auxiliar no seu acompanhamento.

## 3. Objetivos

O objetivo geral é desenvolver um Sistema de Gerenciamento de Estoque capaz de auxiliar no controle dos produtos armazenados, suas quantidades, localizações e movimentações.

Entre os objetivos específicos estão o cadastro de produtos, atualização do estoque, rastreamento da localização, registro de movimentações e geração de relatórios.

## 4. Metodologia Scrum

O desenvolvimento foi organizado utilizando Scrum, com três sprints:

- Sprint 01 — Análise e Planejamento.
- Sprint 02 — Estruturas de Dados e Algoritmos.
- Sprint 03 — Casos de Uso e Finalização.

O acompanhamento das atividades foi realizado por meio do quadro Scrum no Trello.

## 5. Tabela Verdade

Foram utilizadas as variáveis:

- P — Cadastro de Produtos.
- E — Atualização de Estoque.
- L — Rastreamento de Localização.
- R — Relatórios.

A expressão lógica utilizada foi:

P ∧ E ∧ L ∧ R

A solução completa é verdadeira somente quando os quatro requisitos são atendidos simultaneamente.

A tabela verdade completa com as 16 combinações encontra-se no documento específico da atividade.

## 6. Estruturas de Dados

Foram definidas as seguintes estruturas:

- Produto.
- Categoria.
- Movimentação.
- Localização.
- Compra.
- NotaFiscal.

Essas estruturas representam os principais conjuntos de informações necessários ao funcionamento da solução.

## 7. Algoritmos

Foram definidos algoritmos para:

- cadastro de produtos;
- consulta de produtos;
- movimentação de estoque;
- registro de entradas;
- registro de saídas;
- atualização do estoque;
- geração de relatórios;
- consulta do histórico de movimentações.

## 8. Casos de Uso

O sistema possui três atores principais:

- Estoquista.
- Usuário.
- Gerente de Setor.

Os casos de uso definidos são:

- Registrar Entrada de Produto.
- Validar Nota Fiscal.
- Emitir Relatório de Posição Semanal.
- Solicitar Compra de Produtos.
- Consolidar Compras.
- Autorizar Compra de Produtos.

Os relacionamentos `<<include>>` foram definidos de acordo com as dependências obrigatórias entre as funcionalidades.

## 9. Evidências

As evidências do desenvolvimento incluem os registros do quadro Scrum no Trello, documentos produzidos durante as atividades e o Diagrama de Casos de Uso.

Os prints do Trello serão organizados na pasta de evidências do projeto.

## 10. Conclusão

O projeto definiu uma solução para os principais problemas apresentados no enunciado, contemplando cadastro de produtos, atualização de estoque, rastreamento de localização, movimentações e relatórios.

Também foram desenvolvidos os artefatos acadêmicos exigidos, incluindo a tabela verdade, estruturas de dados, algoritmos, casos de uso e documentação das sprints.
